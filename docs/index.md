# TimBearCity.MediaWiki

An unofficial .NET client for the [MediaWiki REST API](https://www.mediawiki.org/wiki/API:REST_API) (`/w/rest.php/v1/`), covering every documented endpoint of
the core API.

```
dotnet add package TimBearCity.MediaWiki
```

- [Guide](../README.md): registering the client, reading and writing pages, revisions, search, files, transforms, errors and diagnostics.
- [API reference](api/index.md): every public type and member, generated from the XML documentation.
- [Changelog](../CHANGELOG.md): what each release added, changed and fixed.
- [Contributing](../CONTRIBUTING.md): commit conventions and the local setup.
